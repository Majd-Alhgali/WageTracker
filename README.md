# يومية عامل — تطبيق متابعة أجر العمل اليومي

تطبيق React Native (Expo) لتتبّع أيام العمل، حساب الأجر الأسبوعي، تسجيل السلف، ومتابعة الرصيد المتبقي. مبني بالكامل باللغة العربية مع دعم كامل لاتجاه RTL، وبتصميم داكن (Dark Mode).

## المتطلبات قبل التشغيل

- Node.js (الإصدار 18 أو أحدث)
- تطبيق **Expo Go** على هاتفك (متوفر على Google Play / App Store)
- اتصال الهاتف وجهاز الكمبيوتر بنفس شبكة Wi-Fi

## خطوات التشغيل

1. فك ضغط المجلد، ثم افتح طرفية (Terminal) داخله.
2. ثبّت الاعتماديات:
   ```bash
   npm install
   ```
3. شغّل المشروع:
   ```bash
   npx expo start
   ```
4. سيظهر رمز QR في الطرفية — امسحه عبر تطبيق **Expo Go** من هاتفك (أو كاميرا الآيفون للـ iOS).
5. سيتم تحميل التطبيق وتشغيله مباشرة على هاتفك.

> لتشغيله على محاكي أندرويد مباشرة: `npm run android`
> لتشغيله على الويب (لأغراض المعاينة فقط): `npm run web`

## المزايا المطبّقة

- **لوحة التحكم:** تعديل الأجر اليومي (القيمة الافتراضية 100,000 ل.س)، زر تسجيل "عمل اليوم" بذكاء يمنع التكرار، 4 بطاقات إحصائية (أيام الأسبوع، أرباح الأسبوع، السلف، الرصيد الصافي).
- **السلف:** تسجيل سلفة بمبلغ وملاحظة وتاريخ، عرض القائمة، حذف أي سلفة بالخطأ.
- **سجل الأيام:** عرض كل الأيام المسجّلة، تعديل قيمة أي يوم أو ملاحظته، حذف يوم بالكامل.
- **تصفير الأسبوع:** زر في الشاشة الرئيسية لبدء أسبوع جديد بعد التصفية (مع تأكيد قبل الحذف).
- **حفظ تلقائي ودائم:** جميع البيانات تُخزَّن محلياً عبر `AsyncStorage` ولا تُفقد عند إغلاق التطبيق.
- **دعم RTL كامل:** جميع النصوص والعناصر محاذاة لليمين، مع فرض `I18nManager.forceRTL(true)`.

## ملاحظة حول RTL

تم فرض الاتجاه عبر `I18nManager` داخل `App.js`. على بعض الأجهزة، التفعيل الكامل للاتجاه على مستوى النظام الأصلي (Native) يتطلب إعادة تشغيل كاملة للتطبيق بعد أول تشغيل (وهذا سلوك طبيعي من React Native وليس خطأ في الكود). جميع الشاشات مصمَّمة بمحاذاة يمين صريحة (`textAlign: 'right'`, `flexDirection: 'row-reverse'`) بحيث تبدو بشكل صحيح حتى قبل اكتمال إعادة التشغيل.
